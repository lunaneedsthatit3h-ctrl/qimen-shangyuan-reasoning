# 第14章：天干克应章

## 核心思想

天干克应不应作为大量口诀死记，而应从三条书内原则推导：尊阳抑阴、尊上抑下、喜合惧冲。组合名称只是压缩后的结果，真正判断还要加入落宫与强弱。

## 核心框架

- **组合五步法**：
  1. 识别天盘干与地盘干的体性。
  2. 判断上下尊卑和主动被动。
  3. 检查生、克、合、冲关系。
  4. 用落宫和十二长生比较实际力量。
  5. 按具体问题翻译为事件语言。
- **喜合惧冲**：合表示联系、约束或合作；冲表示分离、激发或正面冲突，仍须看谁受益。
- **尊阳抑阴**：书内以木火生发为较积极、金水收降为较消极的基础评价轴，不能脱离语境机械套用。

## 关键概念

- **天盘干**：偏动态、当前、外显的作用方。
- **地盘干**：偏静态、基础、承受方。
- **克应**：两干组合在具体任务中的事件映射。
- **来格/去格**：相同两干因上下次序不同而形成的方向差异。
- **上下尊卑**：位置关系对力量表达的修正。

## 思维模型

- 把两干看成一个有方向的句子：上干是正在施加的动作，下干是基础或对象。
- 口诀是索引，不是证据；先重建关系，再核对传统名称。

## 反模式

- **背名称直接输出结论**：忽略问题、落宫和力量。
- **把相同两干的顺序视为等价**：丢失主客方向。
- **一见合即吉、一见冲即凶**：合也可能合绊，冲也可能冲开阻塞。

## 参考表

| 检查层 | 核心问题 |
|---|---|
| 体性 | 两干各自倾向什么？ |
| 位置 | 谁在上、谁主动？ |
| 关系 | 生克合冲属于哪种？ |
| 力量 | 落宫后谁真正有力？ |
| 语境 | 在当前问题中映射成什么？ |

## 演练示例

分析戊加庚的投资问题：戊可表示资本，庚表示阻力。若戊旺庚弱，阻力存在但未必造成重大损失；若戊衰庚旺且再受刑冲，资本受损风险显著。结论来自关系链，而不是“戊加庚凶”的单句口诀。

## 要点

1. 每个克应都要经过五步推导。
2. 上下顺序决定作用方向。
3. 固定格名不能跳过落宫强弱。
