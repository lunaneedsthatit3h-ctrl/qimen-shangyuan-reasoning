# qimen-shangyuan-reasoning

基于《奇門遁甲上元經評述》整理的 Codex Skill，用于柴补奇门飞盘/转盘排盘及有明确出处边界的传统文本推演。

## 安装

将整个仓库放入 Codex 能识别的 Skills 目录，确保最终存在：

```text
qimen-shangyuan-reasoning/SKILL.md
```

安装后重新打开 Codex 任务。

## 调用示例

```text
$qimen-shangyuan-reasoning 以现在时间，占我多久开学
```

也可以指定时间、地点、问题时限，以及使用飞盘或转盘。

## 测试重点

- 当前或指定时间能否正常起局
- 飞盘、转盘选择是否有明确依据
- 是否展示四柱、节气、定局、值符值使、九宫盘等关键结果
- 吉凶与应期判断是否标明原书依据、代码实现和推断边界

本项目用于传统文化文本研究与软件测试。占测和医疗相关内容不属于经验证的事实，也不能替代现实决策或专业意见。
